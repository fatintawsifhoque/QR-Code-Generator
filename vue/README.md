# 📱 QR Code Generator

A clean, responsive, and fully functional QR Code Generator built with **Vue 3** and **Tailwind CSS**. 

This project focuses on leveraging Vue's powerful reactivity system and two-way data binding to create a smooth, intuitive user experience for generating QR codes on the fly.

---

### ✨ Features

- **Vue 3 Composition API:** Built using the modern `<script setup>` syntax for clean, concise, and highly readable code.
- **Effortless Two-Way Binding:** Utilizes Vue's `v-model` for seamless input handling without the need for manual event listeners.
- **Smart Default State:** Initializes with a default QR code (linking to my GitHub profile) so the UI is never empty on first load.
- **Direct Reactivity:** Updates the QR code image instantly by simply mutating the reactive `ref` variable upon button click.
- **Custom Tailwind UI:** Features a unique, hand-crafted design with a lime-green theme, dotted borders, and smooth active-state transitions.

---

### 🛠️ Tech Stack

- ⚡ **Vue 3** (Composition API & `<script setup>`)
- 🎨 **Tailwind CSS** (Utility-first, custom-styled UI)
- 🌐 **QR Server API** (Free, reliable QR code generation)
