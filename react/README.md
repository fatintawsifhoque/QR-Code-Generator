# 📱 QR Code Generator

A simple, clean, and fully functional QR Code Generator built with **React** and **Tailwind CSS**. 

This project focuses on clean state management and a smooth user experience, allowing users to instantly generate QR codes for any text or link.

---

### ✨ Features

- **Instant QR Generation:** Uses the free `qrserver` API to generate scannable QR codes on the fly.
- **Smart Default State:** Loads with a default QR code (linking to my GitHub profile) so the UI never looks empty.
- **Intelligent Reset Logic:** If the user clicks "Generate" with an empty input, it smartly resets the view back to the default GitHub QR code.
- **Auto-Clear Input:** The input field automatically clears itself after generating a new QR code, keeping the interface clean for the next entry.
- **Custom UI/UX:** Styled with Tailwind CSS featuring a unique lime-green theme, dotted borders, and a custom animated footer.

---

### 🛠️ Tech Stack

- ⚛️ **React** (Functional Components & `useState` Hook)
- 🎨 **Tailwind CSS** (Utility-first styling)
- 🌐 **QR Server API** (For generating the QR codes)
